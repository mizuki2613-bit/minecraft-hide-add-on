# Minecraft Hide Datapack & Add-On

プレイヤーがブロックに変身して身を隠す、Prop Hunt 系の Minecraft Datapack / Add-On です。

### Java Edition の対応バージョン

Minecraft Java Edition 26.2 Snapshot 6 ~ 26.3 Snapshot 3  
※ 上記バージョンを対象としており、それ以外のバージョンでの動作は保証しません。

## インストール方法

### Java Edition

1. [Releases](../../releases) ページから最新の`Hide-DataPack.zip` をダウンロードします。
2. ダウンロードした`Hide-DataPack.zip` を Minecraft のワールドフォルダ内の datapacks フォルダに配置します。
3. ワールドを再読み込みするか、`/reload` コマンドを実行します。

### Bedrock Edition

1. [Releases](../../releases) ページから最新の`Hide-Add-On.mcpack` をダウンロードします。
2. ダウンロードした`Hide-Add-On.mcpack` をダブルクリックしてインストールします。
3. 既存のワールドまたは新規作成するワールドでビヘイビアーパックとリソースパックを有効にします。

## 使い方

1. 作業台で棒を3個使ってアイテム「Transform into block」（Add-On では「ブロックに変身」）を作成し、オフハンドに持ちます。
2. 変身したいブロック（ほとんどのフルブロックが対応しています）をメインハンドに持ちます。
3. 歩いたり、スニークしたりせずに、5 秒ほど待機すると変身できます。
    - プレイヤーが立っている場所に空気ブロックがない場合は、変身できません。
4. 変身を解除する方法：
    - **Shift キーを押す**：自分で解除する
    - **ブロックが破壊される**：自動的に解除する
    - **攻撃を受ける**：自動的に解除する
