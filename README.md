# Minecraft Hide Datapack & Add-On

プレイヤーがブロックに変身できるMinecraftのデータパック及びアドオンです。

## インストール方法

### Java版

1. このリポジトリをダウンロードします
2. `java-datapack/hide` フォルダをMinecraftのワールドフォルダ内の `datapacks` ディレクトリに配置します
3. ワールドを再度読み込みするか、`/reload` コマンドを実行します

### 統合版

1. `hide.mcpack` をダウンロードします
2. ダウンロードしたファイルをダブルクリックしてインストールします
3. 既存のワールド、または新しく作成するワールドでビヘイビアーパック、リソースパックを有効にします

## 使い方

1. 作業台で棒を3個使ってアイテム「Transform into block」（アドオンでは「ブロックに変身」）を作成し、オフハンドに持ちます

2. 変身したいブロック（ほとんどのフルブロックが対応しています）をメインハンドに持ちます

3. スニークキーを押さずに5秒ほど待機すると、ブロックに変身します
    - プレイヤーがいるブロックが空気以外の場合は、変身することができません

4. 変身を解除する方法：
    - **シフトキーを押す**：自分で解除
    - **ブロックが破壊される**：自動的に解除
    - **攻撃を受ける**：自動的に解除
